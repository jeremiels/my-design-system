# Premiers pas

Dans ce tutoriel, vous affichez des composants du socle dans une application Vite. Vous changez ensuite un token, puis le thème. Comptez dix minutes.

Le socle n'est pas publié. L'application installe ses trois packages depuis les archives que produit `npm pack`, comme le ferait un registre.

## Prérequis

- Node 26 et npm 11.12, ou une version plus récente.
- Ce dépôt, avec ses dépendances installées (`npm install`).

## 1. Empaquetez le socle

À la racine du dépôt, lancez :

```sh
npm run build
npm pack -w @unicorne/tokens -w @unicorne/icons -w @unicorne/components
```

`npm pack` crée trois archives :

- `unicorne-tokens-0.0.0.tgz` : les tokens, pour toutes les plateformes ;
- `unicorne-icons-0.0.0.tgz` : les icônes ;
- `unicorne-components-0.0.0.tgz` : les composants web.

## 2. Créez l'application

À côté du dépôt, créez un dossier et installez Vite, Lit et le socle :

```sh
mkdir mon-app && cd mon-app
npm init -y
npm pkg set type=module
npm install vite lit ../my-design-system/unicorne-tokens-0.0.0.tgz ../my-design-system/unicorne-icons-0.0.0.tgz ../my-design-system/unicorne-components-0.0.0.tgz
```

Lit, `@unicorne/tokens` et `@unicorne/icons` sont des peer dependencies de `@unicorne/components` : l'application les installe une seule fois.

## 3. Chargez les styles et enregistrez les composants

Créez `main.js` :

```js
import "@unicorne/components/styles.css";
import "@unicorne/tokens/tokens.css";
import "@unicorne/components/define";
```

- `styles.css` déclare les couches de cascade du socle.
- `tokens.css` contient les valeurs des tokens. Sans cette feuille, les composants s'affichent sans couleurs ni espacements.
- `define` enregistre tout le catalogue avec le préfixe `u` : `u-button`, `u-modal`…

## 4. Affichez des composants

Créez `index.html` :

```html
<!doctype html>
<html lang="fr">
  <head>
    <meta charset="UTF-8" />
    <meta name="color-scheme" content="light dark" />
    <title>Mon app</title>
    <script type="module" src="./main.js"></script>
  </head>
  <body>
    <u-button>Enregistrer</u-button>
    <u-button variant="danger">Supprimer</u-button>

    <u-modal label="Confirmation">
      <u-button slot="trigger">Ouvrir la modale</u-button>
      <p>Voulez-vous continuer ?</p>
    </u-modal>

    <u-alert type="success">Modifications enregistrées.</u-alert>
  </body>
</html>
```

Lancez le serveur de développement :

```sh
npx vite
```

Ouvrez l'adresse affichée (`http://localhost:5173`). Vous voyez deux boutons, bleu et rouge, un troisième bouton qui ouvre la modale, et une alerte verte avec son icône.

- L'attribut `variant` choisit la couleur du bouton.
- Le slot `trigger` contient l'élément qui ouvre la modale.
- L'attribut `label` donne son nom accessible à la modale.
- L'alerte affiche l'icône de son type. Le navigateur télécharge seulement le module de cette icône, pas tout le set.
- La balise `meta` `color-scheme` annonce les thèmes clair et sombre au navigateur, avant le chargement des feuilles.

## 5. Réagissez à la fermeture de la modale

Ajoutez à `main.js` :

```js
document.querySelector("u-modal").addEventListener("u-close", () => {
  console.log("Modale fermée");
});
```

Ouvrez la modale, puis fermez-la avec Échap ou avec son bouton de fermeture. La console affiche « Modale fermée ».

## 6. Changez un token

Créez `style.css` :

```css
u-button {
  --u-button-border-radius: 0;
}
```

Importez-la à la fin de `main.js` :

```js
import "./style.css";
```

Les boutons perdent leurs coins arrondis. Un token posé sur l'hôte s'applique à toutes les variantes du composant.

## 7. Passez en thème sombre

Ajoutez `data-theme="dark"` à la balise `<html>` :

```html
<html lang="fr" data-theme="dark"></html>
```

Les couleurs des boutons s'éclaircissent. Le fond de la page passe en sombre. Sans cet attribut, le thème suit la préférence du système.

## Et ensuite

- Les attributs, slots, parts, tokens et événements de chaque composant sont dans sa page, sous **Components**.
- Les tokens et leurs niveaux sont décrits dans [Tokens et couches CSS](?path=/docs/documentation-référence-tokens-et-couches-css--docs).
- Pour créer votre propre design system à partir du socle, suivez [Créer un design system de marque](?path=/docs/documentation-guides-créer-un-design-system-de-marque--docs).
