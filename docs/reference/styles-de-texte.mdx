# Styles de texte

Un style de texte réunit une police, une taille, une graisse, un interligne et un espacement des lettres. Les décisions sont dans l'[ADR 0051](?path=/docs/documentation-adr-0051-styles-de-texte--docs).

- Chaque style est un token `typography` du groupe `text`, au niveau sémantique. Chaque partie est un alias d'un token `font`.
- Une marque change un style par ses tokens `font` : sa police, ses tailles. Ses classes portent son préfixe : `acme-text-heading-xl`.

## Dans le HTML

Donnez la classe d'un style à n'importe quel élément.

```html
<h1 class="u-text-heading-xl">Demandes</h1>
<h2 class="u-text-heading-xl">Mes demandes en cours</h2>
<p class="u-text-body-sm">Mise à jour il y a 5 minutes.</p>
```

- Choisissez la balise d'un titre selon la structure de la page, et sa classe selon son importance.
- Les classes sont dans `tokens.css`, dans la couche `u.utilities`. Une marque les écrit dans sa feuille, sous son préfixe.
- Une classe suit la marque et le thème de sa zone : ses `var()` se résolvent sur l'élément.

## Dans le CSS

Appliquez un style par le raccourci `font`, et son espacement des lettres à part :

```css
.card-title {
  font: var(--u-text-heading-md);
  letter-spacing: var(--u-font-letter-spacing-normal);
}
```

- Le raccourci `font` ne porte pas d'espacement des lettres.
- Le raccourci sert aussi dans le shadow DOM d'un composant de marque : une custom property traverse le shadow DOM, une classe non.
- `font` remet à leur valeur initiale les propriétés qu'il ne cite pas, comme `font-style` et `font-variant`.

## Dans Figma

- Un style devient un style de texte : `text.heading.xl` donne `text/heading/xl`.
- Sa police, sa graisse, sa taille et son espacement des lettres se lient aux variables de leurs tokens.
- Son interligne est un pourcentage du style : 125 % ou 150 %. Tokens Studio lit un interligne sans unité en pixels.

## Vérifier

- `npx unicorne token text.heading.xl` donne la classe, le CSS et les parties d'un style. `npx unicorne tokens text` donne les règles d'usage des styles.
- `check` signale une classe `u-text-…` qu'aucun style ne porte (`unknown-text-style`), avec une suggestion.
- `check` signale un raccourci `font` brut qu'un style porte (`raw-value`), et le corrige en `var(--u-text-…)`.

## Ajouter un style

1. Écrivez le token dans `packages/tokens/src/semantic/semantic.tokens.json`, sous `text`, avec ses cinq parties en alias.
2. Donnez-lui une `$description` : l'usage du style.
3. Lancez `npm run tokens` : la classe et la ligne du manifest se génèrent.
4. Ajoutez son usage, en français, au tableau de cette page (`usage`).
