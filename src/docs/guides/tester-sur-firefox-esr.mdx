# Tester sur Firefox ESR 115

Ce guide lance les vérifications de `tests/legacy/` sur le `dist/` livré, dans Firefox ESR 115, le plus ancien Firefox de la [matrice](?path=/docs/documentation-référence-support-navigateurs--docs).

## Prérequis

- Linux x86_64.
- Sur une distribution récente, la bibliothèque `libdbus-glib-1-2` :

  ```sh
  sudo apt-get install libdbus-glib-1-2
  ```

## Lancer les vérifications

1. Lancez `npm run test:legacy`.
2. Lisez le résultat : une ligne `✓` ou `✗` par vérification.

La commande construit le socle, puis lance `tests/legacy/run.mjs`. Ce script :

- installe Firefox ESR 115 dans `~/.cache/firefox-esr/` avec `scripts/install-firefox-esr.sh`, et vérifie sa somme SHA-256 ;
- sert `tests/legacy/index.html`, qui charge `dist/` et Lit par une import map ;
- exécute `tests/legacy/checks.js` dans Firefox, par WebdriverIO et geckodriver.

## Tester un autre binaire Firefox

1. Lancez `npm run build`.
2. Lancez `FIREFOX_ESR_BIN=/chemin/vers/firefox node tests/legacy/run.mjs`.

## Ajouter une vérification

1. Ajoutez le composant à `tests/legacy/index.html`, s'il n'y est pas.
2. Ajoutez un appel à `check()` dans `tests/legacy/checks.js`. La fonction renvoie `[réussite, détail]`.
3. Écrivez une syntaxe que Firefox 115 comprend : `checks.js` n'est pas transpilé.
4. Lancez `npm run test:legacy`.
